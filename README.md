# Diabetes Risk Assessment System

A web-based Diabetes Risk Assessment application developed using **Python, HTML, CSS, and Machine Learning**.
This project predicts the possibility of diabetes based on user health inputs and provides an easy-to-use interface for risk analysis.

---

## Features

* User-friendly web interface
* Diabetes prediction using Machine Learning
* Fast and accurate risk assessment
* Input validation
* Responsive design
* Real-time prediction result
* Easy deployment and customization

## Usage

1. Open browser
2. Go to:

```plaintext
http://127.0.0.1:5000
```

3. Enter health details:

* Glucose Level
* Blood Pressure
* BMI
* Insulin
* Age
* Pregnancies

4. Click **Predict**

5. View diabetes risk result

## Machine Learning Model

The system uses a supervised Machine Learning classification algorithm trained on diabetes health datasets.

Possible algorithms:

* Logistic Regression
* Random Forest
* Decision Tree
* Support Vector Machine (SVM)
